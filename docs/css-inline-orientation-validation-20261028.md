## 实现

- 新增可选 `TextOrientationProvider` 与 `jalium_text_format_set_orientation`，传递来源方向及父级基线。保留已有 TextFormat、段落 provider 的 vtable 和 span ABI。缺少能力的后端返回不支持。
- 托管原生段落的字体缓存区分方向，使用私有格式传递不同范围；方向一致且与父级一致时继续使用原有整段创建路径。横排与 sideways 书写模式继续使用水平排版规则。
- 原始 Run／Span 与共享 TextBlock 的真实 CSS 消费者传递来源方向。局部 upright 使用隔离字符塑形、竖排度量与强 LTR；mixed 与 sideways 的字形及字体特性按各自范围处理，公共 UTF-16 与原始节点保持不变。
- 共享段落从父级格式化上下文读取方向与主导基线。来源文字行也使用父级基线，避免局部 sideways 把共享行高和绘制位置横移 12 像素。子元素计算的 RTL 保留，可继续继承。

规则依据：[CSS Writing Modes 4 文字方向](https://www.w3.org/TR/css-writing-modes-4/#text-orientation)、[基线](https://www.w3.org/TR/css-writing-modes-4/#text-baselines)。

像素参考使用原生段落和字面的物理列矩阵，不经过共享槽分配器。原生范围行为另有独立字格宽度、正向排序、命中与 UTF-16 断行断言。每个实际目标都设置并断言 RenderingEngine；Metal 在独立可执行程序的 OS 主线程创建原生窗口表面并读回。子进程程序集与测试输出逐个校验 SHA-256。

初次旧原生载荷对照的 29 项全部失败；范围能力接入后 29／29 通过。扩展到实际像素时，83 项中 18 项失败，均为共享消费者的父级／局部基线组合；修正后扩展的 96 项全部通过，另补显式方向控制检查。失败日志与 PNG 均保留，未放宽像素阈值。

首次全量候选为 21,111 项中通过 20,985、失败 126；同一冻结输入去掉本轮 CSS 修改的基线为 21,014 项中通过 20,918、失败 96，二者都为 0 跳过、超时。这 96 项共同失败和额外 30 项资源线程异常没有归为通过。继续检查发现，新 `MessageBoxBehaviorTests.Fixture` 把整份默认主题永久注册到进程全局，同时又在自己的对话框本地挂载它；全局注册不随夹具关闭或主题重置撤销。移除重复的全局注册，继续使用既有的对话框本地资源，消息框内容、交互和断言均未减弱。

独立诊断直接调用原夹具资源工厂：原基线注册数从 0 变为 1，主题重置后仍为 1，随后换线程解析按钮样式在 `ResourceDictionary.DeferredResourceEntry.GetValue` 抛出异常；修正后注册数始终为 0，同样解析通过。完整记录见 `theme-isolation-proof.json`。修正后完整聚合 21,111 项全部通过，原先 126 项失败全部消失。先前的简单同控件跨线程调用没有触发这个注册／重置链路，其未复现日志也保留在 `thread-resource-probe/`，未冒充失败重现。

本轮重新构建八个原生 dylib。两个 metallib 复用上一轮已验证产物；比较 771 个原生输入，变化仅在本轮拥有的八个非着色器文件，完整来源与 SHA-256 见 `native-shader-provenance.json`。实际 Vello 断言通过，未把回退到 Impeller 当成 Vello 验收。

## 实际窗口

最终代码和完整依赖打包为自包含 macOS 验收应用，签名与加载载荷一致性已验证。实际 Metal 窗口保留 57 个事件、56 份原始文字／节点／几何快照与 23 张已查看截图，应用已正常关闭。

- 父级与局部分别切换 mixed／upright／sideways，覆盖五种书写模式、LTR／RTL、短列与长列。
- 原始 Run／Span 身份不变。跨列拖选得到原文 `2+10`：`玄黄ABCאב宇宙洪`；Command+A 得到完整 13 个 UTF-16 单元。另一个原始 TextBlock 可独立全选 `天地玄黄`。
- Tab 移动到按钮，绿色焦点可见；空格实际切换模式，选区保留。
- 检查 1040×660、860×590 与原生系统缩放后的 1920×943。系统缩放需执行原生取消缩放，再恢复初始尺寸；夹具的尺寸重置按钮本身不取消系统缩放。
- 最终全部来源几何与初始状态一致，三块文字及行内装饰区域的解码像素相同。没有声明整个窗口逐像素相同，标题栏、焦点和指针反馈会变化。

可访问性检查读取了语义文字、按钮及焦点状态；没有完成实际旁白朗读、物理键盘、IME 或手拖窗口边框验收。
