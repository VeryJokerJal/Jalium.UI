## 实现行为

- `offset-anchor:auto` 和显式位置共用实际参考盒。布局盒的 content／fill 使用 padding、border 内缩后的内容矩形，border／stroke／view 使用边框矩形。原生、CSS 状态、百分比 padding、尺寸变化和参考盒切换会更新缓存的路径变换。
- 自动锚点在没有作者原点贡献时采用参考盒中心；有本地值、`SetCurrentValue`、绑定或原生／CSS 原点动画时使用有效原点。即使有效数值仍为 `(0,0)`，来源变化也刷新路径。重复的同值动画帧不重复报告变换变化；取消、移除和原生 HoldEnd 继续保留各自语义。
- 位置语法复用现有背景位置解析器，保留单关键字、重排关键字、三／四值边缘偏移和表达式。显式锚点／起点的过渡与关键帧保留混合长度、百分比及远端偏移；距离动画按真实路径长度解析。相对单位使用真实字体、根字体、容器和视口，不再使用虚构的 100px／16px 上下文。
- `ray()` 接入显式 `at <position>`，其余参数可按语法调整次序。圆／椭圆省略 `at` 时可使用显式 `offset-position`。等价路径改为最右侧起步、顺时针前进，修正旧 M1 测试从顶部起步的错误预期。
- 普通变换、路径旋转和位移保持组合顺序，保留三维深度与透视信息，绘制、坐标转换和原内容命中使用相同结果。连续帧从直接绘制切换到缓存层时，为抗锯齿外缘保留捕获边距。

规范依据：[Motion Path 1 的锚点](https://www.w3.org/TR/motion-1/#offset-anchor-property)、[ray()](https://www.w3.org/TR/motion-1/#ray-function)、[等价路径](https://www.w3.org/TR/motion-1/#equivalent-path)、[Transforms 1 参考盒](https://www.w3.org/TR/css-transforms-1/#transform-box)。Motion Path 当前公开版本为工作草案。

## 验证记录

冻结根为 `artifacts/css-motion-reference-boxes-20261028-1f480b7b/`，起始 Git 可见输入 4,584 个。最终 macOS 聚合回归 **23,703／23,703** 通过，0 失败／跳过／超时，命令用时 **1,528.3 秒**（约 25 分 28 秒）。R16 的 23,060 项精确名称与重复次数全部保留；其中圆路径旧方法的断言按规范纠正，不能说所有旧断言字节不变。新增正式用例 **643 项**，含 271 项几何／来源／动画／上下文和 372 项像素用例，全部执行。冻结候选专项回归 **1,028／1,028** 通过，使用相同的最终测试和八个产品程序集。

最终 271 项几何测试换载逐一核对的八个 R16 框架程序集时，**196 失败、75 个控制项通过**；测试程序集 SHA 与正式全量完全相同。这是用例数，不表示 196 个互不相同的产品缺陷。见 `negative-final/`、`legacy-case-retention.json` 与 `final-full/`。

原生选定 CTest **65／65** 通过，注册 117 项，平台／媒体模式排除 52 项，清单本轮重新读取。复用实际 R11 原生构建，与 R16 和实际构建冻结源核对的 822 个 native／Apple 输入相同，未重新编译原生库。构建无错误，99 个唯一诊断位置／66 个文件诊断组与基线一致，无新增诊断组。

按相同精确名称的中位数汇总，23,041 个共享名称的用例时长合计约为 1,388.0→1,441.5 秒，新增约 81.4 秒；没有出现同时增加至少 1 秒且达到八倍的新增离群项。该顺序执行记录不是受控基准，也不说明整体应用性能已验收。见 `duration-comparison.json`。

历史诊断须分别理解：首批 215 项对旧运行库有 140 项失败，其中两项测试误认为 CSS padding 可以覆盖原生本地值；已清除该测试本地值。后续根容器居中偏移和 CSS 四值 padding 次序的测试设置也已修正。最终反向对照使用最终测试程序集和逐一核对的八个 R16 框架程序集，早期计数不能代替最终对照。

连续像素最初有六项失败。测试先改为与真实 Window 一致的持续绘制目标，排除跨目标资源生命周期差异；余下四个 Metal 场景暴露缓存层裁掉抗锯齿外缘，产品修复后相关 18 项检查全部通过。独立参考保留完整物理位置和真实字体，不放宽 RGBA 比较。后续圆／椭圆和 ray 起点的三个失败按规范修复，不改写为旧实现的预期。

## 原生交互与仍开放的像素问题

最终原生实例使用中文蓝白验收页，三个区域比较自动锚点、百分比锚点和显式 CSS 原点。实际查看 33 张 `verified-*` 截图，检查 1100×760 和 920×700 客户区；六个原始 Ruby TextBlock、九条原父子关系保持不变。改变 padding、参考盒、原点来源、90° 旋转、路径位置和窗口宽度后，均实际拖选两个注音字符，再用键盘全选六个；三组初始来源也分别检查。Tab 到达按钮时出现绿色焦点环，空格实际改变内边距。

一次由按钮触发的 CSS 路径过渡记录 711 次变换通知和 237 个主卡片不同位置，范围约 98.85→138.67px；同时实际查看中间／结束画面，结束后再次选择原文。不能把通知数等同于逐帧 GPU 画面数。最终实例记录 792 个事件、791 个快照，自动原点没有被写入本地层；三次应用进程均已关闭。最终八个框架程序集、八个原生库 UUID／文件后备节、两个 shader 和自包含运行库的身份另见 artifact 证明。

六组**稳定状态往返**的完整内容区域 `(25,130)-(1075,550)` 解码 RGBA 相同，指针光晕所在控制区未纳入比较。但初帧与最终稳定帧仍有 16,642 个 RGBA 字节不同，差异局限于第一组文字／边框区域，原因尚未完全隔离，**不报告初帧与缓存帧严格一致**。早期颜色对比不足的实例也不计入最终视觉证据，最终实例给原文设置明确的深蓝前景。

额外连续绘制诊断使用纯原生的字面位移，分别换载逐一核对的八个 R16／R17 框架程序集，排除锚点修复的影响。每种后端有整数、1/4 与 2/3 像素位置、各四帧，共 12 项：两种 Metal 组合从 R16 的 3 通过／9 失败变为 R17 的 12／12；Software 两侧均为 6 通过／6 失败，分数位置的缓存帧差异仍存在。该额外诊断与原生 Ruby 初帧问题分别保留，均**不混入正式套件通过计数**。详见 `fractional-cache-probe/comparison.json`、`cache-stability-diagnostic.json` 和 `live-ui-summary.json`。
