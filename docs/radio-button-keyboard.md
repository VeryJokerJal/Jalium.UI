# RadioButton 方向键与 Gallery 验证

## 行为

- 右/下选择下一项，左/上选择上一项，首尾循环；水平方向遵循 RTL 布局。
- 焦点移动后走普通激活路径，执行目标的 Click 和 Command，使 Gallery 的单向绑定视口选项也更新实际预览。
- 跳过隐藏、禁用、不可聚焦及命令不可执行的目标；保留已有 IsChecked 绑定。
- 有名组限定在同一视觉根，无名组限定为直接兄弟；其他窗口中的同名组不被取消选中。
- 修饰键组合保留原处理路径；ToolBar 内的方向键继续由工具栏导航处理。

普通组的方向键约定参考 [WAI Radio Group Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/radio/)。此处为原生控件行为验证，不作为完整 Web ARIA 符合性声明。
