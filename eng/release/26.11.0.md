Jalium.UI 26.11.0 adds macOS hosting and Metal rendering, expands CSS authoring and stylesheet loading, and includes the current control, input, template and accessibility fixes.

Gallery builds use the same framework release source and Gallery revision `e2bfd9ac0a4db8072bf8b5d7ba908bbec214fda1`.

| Platform | Download | Requirements |
| --- | --- | --- |
| Linux | `Jalium.Gallery-26.11.0-linux-x64.tar.gz` | x64, glibc 2.31+, X11 or Wayland; the .NET runtime is included |
| macOS | `Jalium.Gallery-26.11.0-macos-arm64.zip` | Apple Silicon, macOS 15+; application bundle |
| Windows | `Jalium.Gallery-26.11.0-win-x64.zip` | Windows 10/11 x64; NativeAOT |
| Android | `Jalium.Gallery-26.11.0-android-arm64.apk`, `Jalium.Gallery-26.11.0-android-x64.apk` | Android 7.0 / API 24+; choose the matching device ABI |

Each archive includes startup instructions, licensing and source provenance. Verify downloads with the companion `.sha256` files or `SHA256SUMS.txt`.

The desktop builds do not have publisher code signing or macOS notarization. Android APKs use SDK evaluation signing; these are Gallery evaluation builds, not store submission packages. A previous installation with a different signing certificate must be uninstalled first.

Release checks cover build success, native payload/export checks, Linux symbol baselines, Gallery automated tests on Linux/macOS, Windows window startup and clean exit, and APK signatures, ABI payloads and ZIP alignment. Physical devices, GPU driver combinations, assistive technologies and every interactive Gallery page are outside those automated checks. This GitHub Release does not publish packages to NuGet.org.
