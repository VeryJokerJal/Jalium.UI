# Jalium.UI 26.11.1

本次更新从 **26.11.0 升级至 26.11.1**，重点完善原生 CSS、可替换控件模板、桌面窗口与输入、文本排版和渲染，同时更新独立 Gallery。

## Gallery

![Gallery 26.11.1 · macOS 实际窗口](https://github.com/VeryJokerJal/Jalium.UI/releases/download/v26.11.1/Jalium.Gallery-26.11.1-preview.png)

- 整理 **121 个示例、9 个分类**，另提供首页、设计令牌和主题工作室；搜索和导航共覆盖 **124 个页面路由**。
- 页面改用具名控件和 `Themes/Pages/*.jalxaml` 默认模板，配合 ViewModel、命令和绑定组织交互，方便替换外观和复用示例。
- 更新实时预览、源码工作台、主题切换和自适应布局，补充 CSS、Razor 相关示例。
- 对齐简体中文、英语、日语、韩语资源，补齐 99 项缺失条目；修复窄屏布局、柱状图空白、无窗口导出标志和语义快照裁剪。
- 调整明暗主题的辅助文字与强调文字颜色，提高已测共享颜色组合的对比度。
- 为 Windows NativeAOT 保留 Gallery 模块的模板、附加属性初始化和 ViewModel 反射契约，修复启动时搜索框附加属性未注册的问题。

## CSS 与控件模板

- 扩展原生 XAML CSS 的层叠、选择器、变量、条件值、逻辑属性、布局、文本和动画实现；保留原生局部值与绑定的优先级。
- 增加 `first-valid()`、`progress()`、`calc-mix()`、数值 `random()`、`sibling-index()`、`sibling-count()` 等值函数，并完善 `attr()`、`env()`、`if()` 和注册属性的计算与失效处理。
- 完善竖排文字、ruby 注音、文本方向、字距、换行、字体度量与变换参考框等路径；补充属性元数据和 CSS 编译工具链，供编辑器查询支持项。
- 将多类控件的默认界面组合迁入 `.jalxaml` 模板，完善换模板、缺少可选部件、卸载和重新挂载时的状态、绑定与事件清理。

CSS 适用范围和待验收项见 [CSS 实现跟踪](https://github.com/VeryJokerJal/Jalium.UI/blob/v26.11.1/docs/css-conformance.md)；本版不宣称完整 CSS 规范符合性。

## 窗口、输入与无障碍

- **macOS：**完善窗口生命周期、系统外观同步、全屏、最小化与还原、owner／模态窗口和原生 Popup；加强键鼠、IME、触控板手势、数位笔、编辑菜单、Dock 与 Writing Tools 集成。
- **macOS 无障碍：**修复选择、焦点、虚拟化项目身份、回收容器和变更通知，减少窗口快照与通知路径的分配。
- **Windows：**增加 AppBar、全屏和组合呈现支持；提供可选的帧呈现握手，完善渲染工作线程、窗口缩放及交换呈现过程中的同步。
- **Linux：**修复窗口尺寸与状态、滚动、主题/API、X11／Wayland 输入归属和回调生命周期等问题；补强原生导出与 Wayland 冒烟检查。
- 补齐 RadioButton 方向键行为，以及选择控件、命令和输入回调中的状态与生命周期处理。

## 渲染、文本与性能

- 优化 D3D12 墨迹批处理、描边遮罩缓存和关闭时的延迟批次清理，改进工作流画布平移等热点路径。
- 修复几何区域、曲线段序列化与转换、SVG 文本等问题。
- 改善富文本表格、列表标记、作者换行、内联背景与嵌入对象的位置映射；修复 macOS 字体字重、文本选择和 Writing Tools 的部分替换与样式保留。

## 包与平台

- NuGet 包统一至 **26.11.1**，完善 Windows、Linux、macOS 和 Android 的原生载荷、CSS 工具链及 AOT 消费端验证。
- Linux NuGet 覆盖 glibc／musl 的 x64／arm64；macOS 包覆盖 Apple Silicon 与 Intel，并按消费端 RID 选择原生资源。
- 修复 macOS 两种 CPU 架构共享托管入口程序集、CSS 运行时重复打包，以及 Android 构建依赖等发布问题。
- Linux Gallery 包按目标架构整理 CSS 工具运行时，移除其他平台副本。

升级时请将应用引用的 `Jalium.UI.*` 包统一至 `26.11.1` 并重新构建。源码部署需使用配套的原生库；已有自定义模板应复查部件绑定、主题和输入行为。

使用对应平台入口包：[Windows](https://www.nuget.org/packages/Jalium.UI.Desktop/26.11.1)、[Linux](https://www.nuget.org/packages/Jalium.UI.Linux/26.11.1)、[macOS](https://www.nuget.org/packages/Jalium.UI.MacOS/26.11.1)、[Android](https://www.nuget.org/packages/Jalium.UI.Android/26.11.1)。
