# Symbol icon outlines

SymbolIconGeometry.cs contains selected SVG path data from Microsoft Fluent UI's
MIT-licensed `@fluentui/react-icons-mdl2` version 1.4.9, and original Jalium vectors.
The upstream license is included as LICENSE.fluentui-mdl2.txt.

Source: https://github.com/microsoft/fluentui/tree/master/packages/react-icons-mdl2
Pinned package: https://registry.npmjs.org/@fluentui/react-icons-mdl2/-/react-icons-mdl2-1.4.9.tgz
Upstream codepoint metadata: packages/font-icons-mdl2/src/data/AllIconNames.json.
No Microsoft font files are redistributed.

The installed Segoe MDL2 Assets font retains native glyphs. On other systems,
exact upstream codepoint/name outlines are preferred; remaining Windows system
symbols use original vectors or monochrome semantic equivalents. Enum aliases
sharing a codepoint share the canonical outline. The complete mapping and
reproducible extraction script are retained in the refactor artifacts.
